This repository contains my winning submission to the DuQuantum 2026 Hackathon. Together with my good friend Omkar, we worked on the Alice and Bob challenge.

Given 24 hours, we were tasked with understanding how Alice and Bob uses the coherent state $|\alpha\rangle$ as its qubit. This required us to understand various concepts like open quantum systems, the Lindblad Master Equation, superconducting qubits, circuit QED, rotating wave approximation, and the interaction picture. We demonstrated our understanding of the bit flip and phase flip error profile of cat qubits, of how to perform optimal readout on cat qubits, and of how the complicated circuit Hamiltonian in 2.4 gives rise to all the dynamics we saw in previous tasks. 



The .md file contains our challenge questions.

main.ipynb contains main our code and write-up submission.
